Computer Vision Concept & System Architecture

CampusFix — Technical Overview

Problem Addressed

Campus maintenance requests in university environments are traditionally reported through disparate channels, leading to ambiguous descriptions, misrouted tasks, and delays. CampusFix proposes an intelligent reporting platform that standardizes fault submissions with photographic evidence, location data, and automatic classification.

Proposed Workflow

  1. User Submission: Staff or students upload a photo of the maintenance issue along with a textual description and facility/room location.
  2. Image Classification: A planned deep learning model analyzes visual features to predict fault category (Electrical, Plumbing, Furniture, Cleaning, HVAC, Other).
  3. Intelligent Dispatch: The system automatically directs the ticket to the corresponding facilities maintenance crew.
  4. Administrative Monitoring: Facility administrators track resolution times, category frequencies, and campus hotspot statistics.

My Personal Contribution

Developing the comprehensive project concept, defining the user workflows and system actors, researching suitable computer vision model architectures, and outlining front-end and administrative interfaces.

Current Status

Concept and System Design Exploration: This project is currently in the architectural planning and conceptual design phase. The image classifier has not yet been trained or deployed, and no metrics or production benchmarks are claimed.

Unsupervised Machine Learning & EDA

Mission Lusail — Clustering Analysis

Project Context

Based on the educational Mission Lusail Kaggle competition dataset, this project investigates how unsupervised machine learning techniques identify underlying patterns, geometric groupings, and anomalies in unlabelled feature spaces.

Technical Investigation

  • Exploratory Data Analysis: Distribution analysis, skewness assessment, and correlation profiling across numeric attributes.
  • Feature Scaling: Applied standard and robust scaling methods to preserve spatial distance integrity during clustering.
  • Algorithm Comparison: Compared partition-based clustering (K-Means with elbow and silhouette heuristic inspection) against density-based clustering (DBSCAN to capture arbitrary shapes and noise isolation).
  • Evaluation: Qualitative visual inspection and silhouette analysis rather than ungrounded claims of final rankings.

Current Status

Practical Clustering Analysis & Experimentation: Carried out as educational unsupervised exploration. Kaggle reference provided for data context.

Deep Learning & Regularization

Neural Network Classification Experiments

Experiment Objective

An educational deep learning project systematically investigating how training configurations, learning rates, layer depths, and modern regularization methods influence neural network convergence, overfitting, and generalizability on binary classification problems.

Architectural Components Studied

  • Sequential ANN Architecture: Dense fully connected layers equipped with Rectified Linear Unit (ReLU) activation functions.
  • Binary Output Layer: Single neuron with Sigmoid activation coupled to binary cross-entropy loss and the Adam optimizer.
  • Regularization Techniques: Tested Dropout rates to suppress co-adaptation, Batch Normalization to stabilize internal covariate shift, and Early Stopping with patience to halt training at peak validation performance.
  • Evaluation Rigor: Tracking Precision, Recall, F1-score, and confusion matrices alongside learning curves to avoid misleading high-accuracy pitfalls on imbalanced distributions.

Current Status

Model Development and Experimentation: Ongoing educational lab experimentation. No fabricated metrics are claimed.
